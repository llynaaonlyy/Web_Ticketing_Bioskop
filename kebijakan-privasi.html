1. Data pribadi yang kami kumpulkan

Aplikasi Cinema's mengumpulkan beberapa data pribadi pengguna yang diperlukan untuk menjalankan fitur pemesanan tiket, meliputi:

  1. Nama lengkap
  2. Email
  3. Password
  4. Nomor HP
  5. Pilihan film dan kursi

2. Penggunaan data pribadi

Data yang dikumpulkan digunakan untuk keperluan simulasi pemesanan tiket, pengelolaan akun pengguna, serta sebagai bagian dari proses pembelajaran dan pengembangan aplikasi.

3. Dasar pemrosesan data

Pemrosesan data dilakukan berdasarkan persetujuan pengguna serta untuk keperluan pembelajaran dan pengembangan sistem ticketing berbasis web.

4. Pembagian data

Data pengguna tidak dibagikan kepada pihak komersial mana pun. Namun, source code aplikasi ini bersifat publik dan dikelola melalui GitHub sebagai media version control dan dokumentasi proyek.

5. Keamanan data

Data disimpan menggunakan LocalStorage serta didukung oleh server Ubuntu sebagai media pengujian aplikasi. Sistem ini bukan merupakan sistem produksi dan hanya digunakan untuk keperluan simulasi pembelajaran.

6. Tentang kebijakan privasi ini

Kebijakan privasi ini dapat diperbarui sewaktu-waktu sesuai dengan pengembangan aplikasi Cinema's.
