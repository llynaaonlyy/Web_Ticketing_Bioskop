Ketentuan Penggunaan

Cinema's

1. Pendahuluan

Halaman Ketentuan Penggunaan ini dibuat untuk memberikan penjelasan kepada pengguna mengenai aturan, hak, dan kewajiban dalam menggunakan website Cinema's. Dengan mengakses dan menggunakan website ini, pengguna dianggap telah membaca, memahami, serta menyetujui seluruh ketentuan yang berlaku.

1.1 Tujuan Website

Website Cinema's merupakan sebuah aplikasi berbasis web yang digunakan untuk melakukan pemesanan tiket bioskop secara online. Website ini dibuat sebagai bagian dari proyek pembelajaran dan pengembangan sistem informasi, sehingga fitur yang tersedia masih dapat dikembangkan lebih lanjut.

1.2 Ruang Lingkup Penggunaan

Website ini dapat digunakan oleh pengguna untuk melakukan pendaftaran akun, login, memilih film, memilih kursi, serta melakukan pemesanan tiket. Pengguna diharapkan menggunakan website ini sesuai dengan tujuan yang telah ditetapkan dan tidak menyalahgunakan fitur yang tersedia.

2. Akun dan Keamanan

Untuk menggunakan beberapa fitur pada website Cinema's, pengguna diwajibkan memiliki akun pribadi. Data yang dibutuhkan meliputi nama lengkap, alamat email, kata sandi, dan nomor telepon.

2.1 Tanggung Jawab Pengguna

Pengguna bertanggung jawab penuh atas keamanan akun masing-masing, termasuk menjaga kerahasiaan email dan kata sandi. Segala aktivitas yang terjadi melalui akun pengguna menjadi tanggung jawab pemilik akun tersebut.

2.2 Penyimpanan Data

Data pengguna pada website ini tidak hanya disimpan menggunakan localStorage, tetapi juga disimpan pada server Ubuntu yang telah disiapkan oleh guru pembimbing. Penyimpanan ini bertujuan untuk meningkatkan keamanan dan keberlanjutan data.

3. Privasi dan Informasi Pengguna

Website Cinema's berkomitmen untuk menjaga privasi pengguna. Informasi yang dikumpulkan hanya digunakan untuk keperluan operasional sistem dan pengembangan website.

3.1 Penggunaan Data

Data pengguna seperti email dan nomor telepon dapat digunakan untuk keperluan komunikasi terkait pemesanan tiket dan informasi layanan. Website ini tidak menjamin sepenuhnya bahwa data tidak dapat diakses pihak lain, terutama karena source code disimpan secara publik di GitHub.

3.2 Publikasi Proyek

Proyek Cinema's dipublikasikan secara publik melalui platform GitHub sebagai bagian dari pembelajaran dan portofolio pengembang. Oleh karena itu, pengguna diharapkan memahami risiko yang mungkin timbul dari penggunaan aplikasi berbasis proyek pembelajaran.

4. Perubahan Ketentuan

Pengelola website berhak untuk mengubah, menambah, atau mengurangi isi dari ketentuan penggunaan ini sewaktu-waktu tanpa pemberitahuan terlebih dahulu. Pengguna disarankan untuk secara berkala membaca halaman ini agar mengetahui perubahan yang berlaku.

5. Penutup

Dengan menggunakan website Cinema's, pengguna dianggap telah menyetujui seluruh ketentuan penggunaan yang berlaku. Apabila terdapat pertanyaan atau kendala dalam penggunaan website, pengguna dapat menghubungi pengelola melalui email yang telah disediakan.
