Tentang Cinema's

Cinema's adalah aplikasi pemesanan tiket bioskop berbasis web yang dikembangkan sebagai proyek individu selama menjalani program magang (PKL) di tingkat pendidikan SMK.

Aplikasi ini dibuat sebagai sarana pembelajaran pengembangan web, mulai dari perancangan antarmuka, alur pemesanan tiket, hingga pengelolaan data pengguna secara mandiri.

Tujuan Pengembangan

  1. Melatih kemampuan pengembangan web frontend dan dasar backend
  2. Memahami alur sistem aplikasi ticketing
  3. Menerapkan penyimpanan dan pengelolaan data pengguna
  4. Membuat tampilan aplikasi yang nyaman dan mudah digunakan
  5. Mengenal proses deployment ke server
  6. Mengenal Version Control menggunakan GitHub

Teknologi yang Digunakan

  1. HTML, CSS, dan JavaScript
  2. Bootstrap 5
  3. LocalStorage sebagai penyimpanan data sementara
  4. Server Ubuntu sebagai media deployment dan pengujian aplikasi (server disiapkan dan dibimbing langsung oleh guru pembimbing)
  5. QR Code Generator
  6. Chart.js untuk visualisasi data aktivitas pengguna

Status Proyek

Aplikasi Cinema's merupakan proyek pembelajaran dan tidak digunakan untuk transaksi nyata. Seluruh data yang ditampilkan hanya untuk keperluan simulasi dan penilaian.

Repositori Proyek
